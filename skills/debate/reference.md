# Start Debate Reference

Scratchpad format: [templates/debate-scratchpad.md](templates/debate-scratchpad.md).

## Team Perspective Definitions

| Team | Role | Focus | Default stance |
|---|---|---|---|
| Red (required) | Challenger | Assumptions, weaknesses, risks, failure modes, logical consistency | "Why this won't work" |
| Blue (required) | Defender | Strengths, supporting evidence, answers to opposition | "Why this will work" |
| Green (optional) | Pragmatist | Feasibility, resources, timelines, incremental or hybrid paths | "How we actually build this" |
| Yellow (optional) | Risk analyst | Security, safety, compliance, edge cases, long-term consequences, safeguards | "What we must protect against" |
| Purple (optional) | Synthesizer | Common ground, false dichotomies, hybrid solutions | "How we combine the best of both" |

## Interventions

After each round, write an intervention to Moderator Notes per failed check.

| Check | Fails when | Type | Guidance |
|---|---|---|---|
| Progress | no new substantive points | Stuck | "Team X, consider: [new angle/question]" |
| Balance | discussion one-sided | Imbalance | "Team Y, respond to Team X's point about [specific]" |
| Relevance | off topic | Astray | "Refocus: The core question is [restate topic]" |
| Depth | claims lack evidence | Shallow | "Team X, provide specific evidence for [claim]" |
| Engagement | teams ignore each other | Disconnected | "Team X, address Team Y's argument about [specific]" |

```markdown
### [MODERATOR] {timestamp}

**Type:** {Stuck|Imbalance|Astray|Shallow|Disconnected}
**Target:** {Team color or "All"}
**Issue:** {Brief description of problem}
**Guidance:** {Specific direction for team(s)}
```

## Common Failure Modes

| Symptom | Fix |
|---|---|
| Teams agree quickly | Sharpen distinctions; assign more adversarial stances |
| Teams ignore the opposition | Have teams quote and answer specific opponent claims |
| A team repeats one argument reworded | Suggest a new dimension: "Consider the [cost/timeline/user] angle" |
| Teams research without committing | Set scope; ask for the "best current argument given available info" |
| Teams converge before exploring disagreements | Probe: "But what about X?" "How do you respond to Y?" |
